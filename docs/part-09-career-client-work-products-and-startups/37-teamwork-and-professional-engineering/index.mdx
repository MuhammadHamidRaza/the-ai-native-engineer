Chapter 37 is where engineering stops being a solo sport. Every system you will build is a team sport with stakes, deadlines, and disagreement baked in — and every hiring bar above junior level tests how you behave in that system as much as how you code.

**Chapter 37 (`6 Focused Hours`)** teaches the social engineering layer that separates engineers who get promoted from engineers who write good code in a vacuum:

- **37.1 Communication & Technical Ownership** — RFCs, design docs, and the estimation craft that makes you reliable to plan against.
- **37.2 Operating Inside Engineering Teams** — three-way collaboration with product and design, mentorship (and being mentored), code review culture, blameless postmortems, and composed incident response.

## What Changes After This Chapter

| Before | After |
| :-- | :-- |
| "I'll be done tomorrow" | Ranges with named risks and a spike plan |
| Specs are PM's job | You read, critique, and extend them |
| Code review = comment nits | Review = correctness, security, failure modes |
| Incident = hero scramble | Incident = IC/operator/comms, calm, timestamped |
| Mentoring = answer key | Mentoring = calibrated stretch + reflection |
| Growth = more LeetCode | Growth = one deliberate artifact per axis per quarter |

## Where These Lessons Lead

Chapter 38 (jobs and interviews) evaluates you on exactly these behaviors. Chapter 39 (client work) makes them your sales process with real money attached. Both chapters lean heavily on the habits installed here — do not skip the exercises.

## Exit Criteria — You Are Done When You Can

- [ ] Write a 1–2 page RFC with quantified problem, Steelmanned alternatives, and a comment window
- [ ] Produce a PERT three-point estimate and communicate it with named risks
- [ ] Facilitate a read-before-build review with PM/design and produce a shared DoD
- [ ] Give feedback in Situation→Behavior→Impact→Request form
- [ ] Run an IC/operator/comms incident structure without panicking the channel
- [ ] Write a blameless postmortem with action items, owners and dates
