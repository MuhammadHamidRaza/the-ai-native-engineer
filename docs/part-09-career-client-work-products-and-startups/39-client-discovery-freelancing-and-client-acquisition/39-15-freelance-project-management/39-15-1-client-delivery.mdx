The project was won on trust; it's lost or won on delivery. This lesson teaches you to manage the engagement like a professional — visible, predictable, low-drama — so clients renew and refer.

## 1. The Delivery Rhythm

Kickoff → 48h plan → daily/weekly check-ins (async Slack or 15-min call) → milestone demos → final handoff. No black boxes; clients hate surprises more than bad news.

## 2. The Delivery Artifact Set

- **Week 1 — Kickoff doc**: goals, milestones, communication norms, escalation path.
- **Weekly — Status report**: done / in progress / blocked / next week; 5 bullets max.
- **Milestones — Demo**: before/after metrics; one slide per milestone is enough.
- **Close — Handoff pack**: README, runbooks, access, architecture diagram, support window.

## 3. Managing Scope Creep

"Nice-to-have X" → "Yes, after launch; let's log it in the backlog." Every "quick add" is a change order in disguise — charge for it or defer it.

## 4. Common Failure Modes

- **Silent weeks** — client panic; report weekly even if quiet.
- **Scope creep by silence** — free extras feel generous but erode margin.
- **No handoff** — knowledge lost; client feels abandoned; referrals die.
- **Missing expectations** — "done" means something different to them than to you; write it down.
- **Single channel of truth** — decisions in DMs are lost; every material decision goes to the kickoff doc or the status report.

## 5. A Complete Kickoff Doc (CareQueue Pilot at Brightside Dental)

```text
KICKOFF — CareQueue Pilot at Brightside Dental (Marisol Vega, Office Manager)
Sprint: 2026-12-01 → 2027-01-09 (5 weeks)

GOALS (success = these three numbers)
1. ≥60% of billing questions auto-drafted and approved by day 45
2. Marisol saves ≥30 min/day by day 45 (self-reported, weekly check-in)
3. Zero patient data leaves the practice's Google Workspace tenant

MILESTONES (each with a demo + invoice trigger)
M1 (wk 2): Connected Gmail, 4 labels live, first batch of drafts — demo Fri 12/12 — $3,000
M2 (wk 4): 2 weeks of approvals/rejections logged, tone tuned — demo Fri 12/26 — $3,000
M3 (wk 5): 30-day usage review + case-study interview — final payment $2,000

COMMS
- Async Slack channel #carequeue-brightside (you + me only)
- Friday 15-min call, 10:00, standing
- Status report every Friday by 17:00: done / in-progress / blocked / next week + one metric
- Escalation: email [you]; if no reply in 4h, WhatsApp [your number]; if urgent, call

OUT OF SCOPE (explicit, so nobody has to argue later)
- Insurance EOB auto-attach; multi-location rollout; patient-facing chat
- Anything touching Dentrix directly (Gmail API only)

CHANGE ORDERS
- New feature = new line item, written quote, 50% deposit, schedule shift in writing
- Verbal "quick adds" default to "next milestone" — never accepted verbally

HANDOFF PACK (M3)
README, runbook, 2 recorded walkthroughs, admin credentials transferred,
30-day support window, referral request at final payment.
```

**Notice:** every number in this document was negotiated before work started, and the client signed it before the deposit cleared. That is what "predictable, low-drama delivery" actually looks like.

## 6. Exercise

Write the kickoff doc for a mock engagement (any product from earlier in the book works — CareQueue, ShopCore front desk, your capstone). Reuse the exact structure above.

**Acceptance criteria.** Your kickoff doc contains: 3 measurable success metrics, dated milestones with invoice triggers, a named comms channel and escalation path, an explicit out-of-scope list, and a change-order clause in writing. A peer should be able to run week 2 from the document alone.
