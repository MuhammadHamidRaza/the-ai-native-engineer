**Purpose:** Your resume is read for 10–30 seconds by a recruiter, then 2–5 minutes by an engineer. Both must find what they need. This checklist makes both happy.

## D.1.1 — The 10-Second Recruiter Scan

| Element | Pass criterion |
| :-- | :-- |
| Name + contact | One line, top of page: Name · Email · GitHub · LinkedIn · Location |
| Headline | One line: "Full-Stack AI Engineer · TypeScript, Python, PostgreSQL" |
| Current role | Most recent first; company, dates, 1–2 bullets max |
| Skills list | Modern stack only (Next.js, FastAPI, Postgres, Docker, AWS) |
| Education | One line, no GPA unless &lt;3 years experience |

**If any of these fail, fix before anything else.**

## D.1.2 — The 2-Minute Engineer Read

| Element | Pass criterion |
| :-- | :-- |
| 2–3 quantified bullets per role | Number + outcome + how: "Reduced p95 latency 480→90ms via index tuning + connection pooling" |
| No fluff | "Spearheaded robust scalable solutions" → delete |
| Tech context | Mention actual tools inline — "Next.js frontend, FastAPI backend, Postgres" |
| Scope signal | Team size, users served, traffic volume — "served 50k DAU at 10k RPS" |

## D.1.3 — The ATS (Applicant Tracking System) Checklist

- [ ] Single column, no tables, no graphics, no headers/footers
- [ ] Standard section names: Experience, Skills, Education, Projects
- [ ] Keywords from the job description echoed (honestly) — e.g., "idempotency", "RAG", "Postgres"
- [ ] PDF format unless specified otherwise
- [ ] File name: `FirstnameLastname-Role.pdf`

## D.1.4 — The Projects Section

For career switchers or early-career: 2–3 projects with:

- One-line outcome: "Built a full-stack invoice reconciliation app used by 3 freelancers"
- Stack: Next.js, FastAPI, Postgres, Stripe
- Link to GitHub (clean README, tests passing)

## D.1.5 — The Final Polish Checklist (Print This)

```text
[ ] One page (unless 8+ years experience — then 2 max)
[ ] No typos (read aloud; spellcheck passes)
[ ] No photos, no "Objective", no "References available upon request"
[ ] Quantified impact in every bullet
[ ] Action verbs, not passive voice
[ ] Tailored skills section per application (honest)
[ ] GitHub link works and is clean
[ ] LinkedIn matches (same headline, same story)
```

## D.1.6 — The Anti-Patterns (Delete These)

- "Team player / detail-oriented / hardworking" — meaningless
- "Responsible for [thing]" — shows you were present, not effective
- "Helped with [thing]" — hides your actual contribution
- "Familiar with [tool]" — means you don't know it; say "Built production X with [tool]" or omit
- "Passionate about technology" — applies to everyone; show, don't tell
