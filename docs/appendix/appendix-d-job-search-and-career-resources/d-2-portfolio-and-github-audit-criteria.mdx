**Purpose:** Engineers hire evidence, not adjectives. Your GitHub and portfolio are the single strongest signal you can send. This audit tells you exactly what to fix.

## D.2.1 — The GitHub Profile Audit

| Element | Pass criterion |
| :-- | :-- |
| Profile README | 4–6 lines: who, what you build, one flagship project, one link |
| Pinned repos (6) | 2 flagships + 1 contribution + 1 learning project + 2 experiments |
| Repo names | Descriptive, not "test" or "junk" |
| README per repo | Problem → Architecture → Run instructions → Live link/screenshots |
| License | MIT or Apache 2.0 |
| Tests | CI badge green; `npm test` passes on clean clone |
| Commit history | Not "initial commit" then nothing — show iteration |

## D.2.2 — The Flagship Repo Checklist

- [ ] One-line tagline in description
- [ ] README with problem/architecture/demo link
- [ ] Live demo (Vercel, Railway, or screenshot)
- [ ] Tests + CI badge
- [ ] Clean code structure (src/, tests/, docs/)
- [ ] No secrets committed (`.env` in `.gitignore`, `.env.example` present)

## D.2.3 — The Portfolio Site Audit

| Element | Pass criterion |
| :-- | :-- |
| Who you are in 5 seconds | "Full-stack AI engineer building production systems" |
| Flagship project with live demo | One click to see it working |
| Case studies | 2–3 with problem/stack/outcome (numbers) |
| Contact | One-click email or calendar link |
| Load time | &lt;3 seconds on 3G (test in DevTools) |
| Mobile | Works without horizontal scroll |

## D.2.4 — The Contribution Graph (Reality Check)

Green squares ≠ proof of skill. **Open-source PRs in real repos** (even docs fixes) > solo green squares. Aim for:

- 1–2 merged PRs in a project you respect, or
- 1 meaningful internal repo at your company, open-sourced, or
- 1 well-documented solo project that demonstrates judgment

## D.2.5 — The Quick Audit (10 Minutes)

Open your GitHub profile cold. Ask:

1. Would a stranger know what you do in 10 seconds?
2. Is there a live link I can click?
3. Can I see tests/CI?
4. Would I want to hire this person?

If any answer is "no" or "unsure", fix it before applying.
