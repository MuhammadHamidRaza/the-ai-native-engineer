**Purpose:** The moment you have an offer, you have leverage — and most engineers leave it on the table. This gives you the evaluation matrix and the negotiation scripts.

> **Scope note:** Figures and bands below are US/EU-market-oriented, illustrative, and **dated (Nov 2026)**. Compensation varies enormously by city, currency, company stage and level — always benchmark with `levels.fyi`, your recruiter, posted salaries on the employer's job ads, and H1B data before quoting numbers. Never treat a book's snapshot as your market clearing price.

## D.4.1 — The Offer Evaluation Matrix

Score each component 1–5:

| Component | Weight | Your score (1–5) | Notes |
| :-- | :--: | :--: | :-- |
| Base cash | 30% | | Market rate? Growth trajectory? |
| Equity/RSUs | 20% | | Vesting, strike, refresh, IPO odds |
| Bonus | 10% | | Target %, payout history |
| Learning | 15% | | Will this make you better in 2 years? |
| Title/scope | 10% | | IC vs management; scope; visibility |
| Team/manager | 10% | | Do you trust them? Their track record? |
| Stability | 5% | | Runway, burn rate, market position |

**Total ≥ 4.0 = strong offer. 3.0–3.9 = negotiate or walk. < 3.0 = walk.**

## D.4.1.1 — Calibrating the Market (illustrative snapshot, Nov 2026 — re-verify)

| Segment | Typical base cash (US) | Typical base cash (EU/UK) | Notes |
| :-- | --: | --: | :-- |
| Senior software engineer (cloud/web) | ~$160k–$230k | ~€70k–€110k / ~£75k–£115k | Equity swings outcomes; check levels.fyi |
| Staff engineer / tech lead | ~$210k–$300k+ | ~€90k–€140k / ~£95k–£140k | Scope matters more than title |
| Remote international, USD-payrolled | ~$150k–$220k | n/a | Bands cluster near 70–80% of SF/NY on-site |
| Early-stage startup | ~$140k–$190k + equity | ~€60k–€95k + equity | Discount base; weight equity realistically |

Rules for using this table:

1. **Bands are a reference, not a verdict.** Benchmark the exact company, level and market first (`levels.fyi`, posted salary ranges on the job ad — many jurisdictions now require them).
2. **Adjust for company stage, equity quality, and cost-of-living**, not just geography.
3. **Your ask should anchor to the employer's own stated band** ("Your posting lists $X–$Y for this level; can we meet $Y?") — posted bands beat any general table.
4. **Levels = leverage.** One level up often beats a bigger percentage bump at the same level.
5. **Non-comp levers** (sign-on, start date, learning budget, remote days, PTO) are often easier to win than base.

If an employer refuses to share any band and markets well above these ranges, that itself is a signal — ask with the ranges visible, or ask for the range explicitly.

## D.4.2 — The Negotiation Playbook

**Step 1 — Never accept the first number.** "I'm excited. Can I have until Friday to review?" — always.

**Step 2 — Anchor with data.** "Based on levels.fyi and my research, the market for this role at this level is $X–$Y. Can you match $Y?"

**Step 3 — Negotiate holistically.**

```text
"Base at $X would work for me. If that's hard, can we do $X-5k +
$10k sign-on, or $X with a 10% equity refresh?"
```

**Step 4 — Always negotiate something.** Even if base is firm, try: sign-on bonus, start date, PTO, Learning budget, remote flexibility, title adjustment.

**Step 5 — Close gracefully.** "If we can get to $X, I'm ready to sign today." Then stop talking.

## D.4.3 — The Red Flags

| Offer | Red flag |
| :-- | :-- |
| No written offer | Never sign; never start |
| Vague bonus/equity | Get it in writing |
| "We're like a family" | Unpaid overtime culture likely |
| No clear level/scope | You'll be under-leveled forever |
| Pressure to sign today | Something's wrong; walk |

## D.4.4 — The Decline Script (When You Walk)

```text
"Thank you — I've decided to go in a different direction. I was impressed
by [specific thing], and I hope we cross paths again. Please keep me in
mind for future roles."
```

**Never burn bridges** — the industry is small and memories are long.

## D.4.5 — The Acceptance Checklist

```text
[ ] Written offer received and reviewed by you (not just HR)
[ ] Base, bonus, equity, vesting schedule all in writing
[ ] Start date, reporting line, scope confirmed
[ ] Benefits: health, 401k match, PTO, learning budget
[ ] No non-compete surprises
[ ] You signed it, or it signed you — either way, done
```
