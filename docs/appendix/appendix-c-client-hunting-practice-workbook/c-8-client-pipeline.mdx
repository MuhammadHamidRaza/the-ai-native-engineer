**Purpose:** A pipeline you don't measure is a pipeline you don't trust. This section gives you the tracking system that makes your numbers honest — and your growth predictable.

## Exercise 1 — The Pipeline Tracker (set up once, use forever)

Build your tracker with these columns:

| Column | What goes here |
| :-- | :-- |
| Company | Name |
| Contact | Name + role + LinkedIn |
| Pain signal | One line, verbatim |
| Stage | Contacted / Replied / Call / Proposal / Close |
| Value | Estimated project size |
| Date entered | When added |
| Date advanced | When stage changed |
| Next action | One specific thing + date |
| Notes | Key insight from last touch |

**Deliverable:** the tracker spreadsheet with all 10 targets loaded.

## Exercise 2 — Stage Definitions (memorize these)

```text
Contacted     — outreach sent, no reply yet
Replied       — they responded, dialogue opened
Call          — discovery call held (or confirmed)
Proposal      — proposal sent, decision pending
Close         — signed; kickoff scheduled
Lost          — said no, or went silent 30+ days
```

**Never skip a stage.** A lead jumping from Contacted to Close without a call is a fantasy, not a pipeline.

## Exercise 3 — The Weekly Pipeline Review (every Friday, 15 min)

Every Friday:

1. How many in each stage?
2. Which moved this week? Why?
3. Which are stuck >14 days? What's the unblock?
4. What's the total pipeline value?
5. Is that ≥3× your monthly target? If not, outreach more.
6. What did you learn about messaging/targeting?

**Deliverable:** 6 bullets in your journal, every Friday.

## Exercise 4 — The Numbers That Matter

| Metric | Healthy | Warning |
| :-- | :-- | :-- |
| Reply rate | ≥15% | &lt;5% → message problem |
| Call rate | ≥30% of replies | &lt;10% → qualification problem |
| Proposal rate | ≥50% of calls | &lt;20% → discovery problem |
| Close rate | ≥30% of proposals | &lt;10% → proposal/pricing problem |
| Avg deal size | ≥$8k | &lt;$3k → niche or positioning problem |

**Deliverable:** your current numbers, honestly. No spin.

## Exercise 5 — The Pipeline Forecast (30 min monthly)

```text
Monthly revenue target: $______
Pipeline value needed: $______ (3× target)
Current pipeline: $______
Gap: $______
Leads to add: ______ (at your close rate)
```

**Deliverable:** one-page forecast, updated monthly.

## Scoring

| Criterion | 1 | 3 | 5 |
| :-- | --: | --: | --: |
| Tracker completeness | Missing columns | Mostly there | Full, live, updated |
| Stage discipline | Skips stages | Sometimes skips | Rigorous |
| Weekly review | Never | Some weeks | Every Friday, in writing |
| Pipeline health | &lt;1× target | 2× target | ≥3× target |

**Target: ≥16/20 for 4 consecutive weeks before you "have a pipeline".**
