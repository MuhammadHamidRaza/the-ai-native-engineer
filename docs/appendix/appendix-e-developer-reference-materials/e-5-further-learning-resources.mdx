- **The Pragmatic Programmer** — Hunt & Thomas — career-long engineering wisdom
- **A Philosophy of Software Design** — John Ousterhout — deep thinking on complexity
- **Site Reliability Engineering** — Google — how to run production systems

- **Stratechery** — business/strategy context for engineers

- **AWS / Google / Netflix Engineering Blogs** — how the best run production
- **Hacker News** — filtered to "Show HN" and "Ask HN" for signal

## Why Not Random Blogs

Blog posts age; official docs don't. When you need an answer, check the official docs first — they're versioned, tested, and maintained. Random blog posts are for inspiration and anecdotes, not API reference.

## Curated Engineering Resources (by domain)

**AI/LLM Engineering:** OpenAI docs (developers.openai.com), Anthropic docs (platform.claude.com/docs), Google AI (aistudio.google.com), LangChain/LangGraph docs, Hugging Face docs.

**Frontend:** React docs, Next.js docs, Tailwind CSS docs, web.dev (Google's performance/UX guidance).

**Backend/DB:** PostgreSQL docs, Redis docs, FastAPI docs, SQLAlchemy docs, pgvector docs.

**DevOps:** Docker docs, Kubernetes docs, GitHub Actions docs, Terraform docs.

**Security:** OWASP Top 10, OWASP API Security, Stripe's webhook signature verification docs.

## The Meta-Skill

The best engineers aren't the ones who memorized the most; they're the ones who can find the answer fastest and apply it correctly. That's why this book teaches you to read docs, not memorize them.
