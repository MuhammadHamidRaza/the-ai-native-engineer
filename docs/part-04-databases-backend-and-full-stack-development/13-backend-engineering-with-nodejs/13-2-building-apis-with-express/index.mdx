**Subchapter 13.2** builds your first real HTTP API: an Express 5 server, REST design done right, middleware and validation that reject bad input at the door, connections to both ShopCore databases, and a complete, tested CRUD API for products.

## Lessons in Subchapter 13.2

1. **[13.2.1 Your First Express Server](/book/part-04-databases-backend-and-full-stack-development/13-backend-engineering-with-nodejs/13-2-building-apis-with-express/13-2-1-your-first-express-server):** `app.js` vs `server.js`, routes, params, JSON bodies, and your first curl verification.
2. **[13.2.2 RESTful Resource Design and Status Codes](/book/part-04-databases-backend-and-full-stack-development/13-backend-engineering-with-nodejs/13-2-building-apis-with-express/13-2-2-restful-resource-design-and-status-codes):** Plural nouns, correct verbs, and the 400/401/403/404/409/429 vocabulary.
3. **[13.2.3 Middleware, Validation and Error Boundaries](/book/part-04-databases-backend-and-full-stack-development/13-backend-engineering-with-nodejs/13-2-building-apis-with-express/13-2-3-middleware-validation-and-error-boundaries):** Zod validation middleware, `AppError`, and a single error boundary registered last.
4. **[13.2.4 Connecting Databases: PostgreSQL and MongoDB](/book/part-04-databases-backend-and-full-stack-development/13-backend-engineering-with-nodejs/13-2-building-apis-with-express/13-2-4-connecting-databases-postgresql-and-mongodb):** `pg` Pools, MongoDB clients, `.env` connection strings, parameterized queries.
5. **[13.2.5 Building a Complete ShopCore CRUD API](/book/part-04-databases-backend-and-full-stack-development/13-backend-engineering-with-nodejs/13-2-building-apis-with-express/13-2-5-building-a-complete-shopcore-crud-api):** The finished products API — full code, curl tests, expected outputs, SQLSTATE translation.
