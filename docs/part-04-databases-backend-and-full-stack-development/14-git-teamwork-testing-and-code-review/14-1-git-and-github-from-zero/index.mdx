**Subchapter 14.1** gets you operational: install Git, verify it, set your identity, create a GitHub account, connect via SSH, and complete the entire clone-branch-PR-merge loop yourself.

## Lessons in Subchapter 14.1

1. **[14.1.1 Installing Git and Creating Your GitHub Account](/book/part-04-databases-backend-and-full-stack-development/14-git-teamwork-testing-and-code-review/14-1-git-and-github-from-zero/14-1-1-installing-git-and-creating-your-github-account):** Windows/macOS/Linux installs, `git config`, SSH keys, `ssh -T git@github.com`.
2. **[14.1.2 Your First Complete Loop: Clone, Branch, PR, Merge](/book/part-04-databases-backend-and-full-stack-development/14-git-teamwork-testing-and-code-review/14-1-git-and-github-from-zero/14-1-2-clone-commit-push-and-your-first-pull-request):** The full solo GitHub workflow, slowly, with every command explained.

Everything in 14.2 and 14.3 assumes this foundation — rebasing and conflict resolution are meaningless before your first PR exists.
