**Chapter 14 (`14 Focused Hours`)** teaches the professional workflows every engineering team runs: Git from installation through pull requests to merge conflicts — then the automated testing pyramid and the code review discipline that keeps `main` releasable.

## Chapter 14 Structure

- **14.1 Git & GitHub from Zero:** Install Git, set your identity, create GitHub, connect SSH, complete your first PR loop.
- **14.2 Collaborative Git Workflows:** GitHub Flow, branch protection, merge vs rebase, conflict resolution, lockfile conflicts, Conventional Commits.
- **14.3 Automated Testing & Code Review:** The testing pyramid with real tools (Node's runner, Vitest, supertest, Playwright), flaky-test elimination, and review standards.

## Why This Chapter Exists

Solo coding hides collaboration skill. The moment you join a team — or contribute to open source — your daily reality is branches and PRs. And without tests and reviews, every merge to `main` is a dice roll. This chapter makes both boring in the best way.

**Prerequisite:** a Git identity (`git config`) and a GitHub account — 14.1.1 covers both if you don't have them yet.
