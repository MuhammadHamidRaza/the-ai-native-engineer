**Subchapter 12.1** is the hands-on on-ramp: from "I have never installed a database" to "PostgreSQL is running, I can see it, I can query it, and I know both the GUI and the terminal" — installed locally on Windows/macOS/Linux, or instantly in a browser with Neon or Supabase.

## Lessons in Subchapter 12.1

1. **[12.1.1 What PostgreSQL Is and Installing It](/book/part-04-databases-backend-and-full-stack-development/12-sql-postgresql-and-mongodb/12-1-install-and-run-postgresql/12-1-1-what-postgresql-is-and-how-to-install-it):** Official downloads, the Windows EDB installer, macOS and Linux options, and the exact verification commands — `psql --version`, service checks, `SELECT version();`.
2. **[12.1.2 pgAdmin 4 From Zero](/book/part-04-databases-backend-and-full-stack-development/12-sql-postgresql-and-mongodb/12-1-install-and-run-postgresql/12-1-2-pgadmin-4-from-zero):** Launch pgAdmin, register your server, create the `shopcore` database, run SQL in the Query Tool, browse tables and columns visually.
3. **[12.1.3 psql Command-Line Essentials](/book/part-04-databases-backend-and-full-stack-development/12-sql-postgresql-and-mongodb/12-1-install-and-run-postgresql/12-1-3-psql-command-line-essentials):** `\l`, `\c`, `\dt`, `\d`, `\du`, running `.sql` files, `ON_ERROR_STOP`, exporting CSV.
4. **[12.1.4 Hosted PostgreSQL: Neon and Supabase](/book/part-04-databases-backend-and-full-stack-development/12-sql-postgresql-and-mongodb/12-1-install-and-run-postgresql/12-1-4-hosted-postgresql-neon-and-supabase):** Create a hosted database with no install — account, project, connection string, SSL, free-tier realities, and password-safe practices.

Finish 12.1 before touching any SQL in 12.2 — you cannot query a database that doesn't exist.
