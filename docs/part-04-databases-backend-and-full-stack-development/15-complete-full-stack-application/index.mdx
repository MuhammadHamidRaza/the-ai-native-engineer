**Chapter 15 (`38 Focused Hours`)** builds **ShopCore** — a complete, production-structured online store: React + Vite frontend, Express 5 backend, PostgreSQL with real migrations, cookie authentication, and a CI-tested checkout flow. No placeholders, no magic — every file, command and expected output.

## Chapter 15 Structure

- **15.1 Foundations & Data Layer:** Requirements, architecture, repository layout — then the canonical ShopCore schema loaded as versioned migrations.
- **15.2 Backend Build:** `pg`-wired Express skeleton, the complete auth module (sessions in Postgres, `HttpOnly` cookies, roles), and the catalog/cart/checkout API.
- **15.3 Frontend Build:** Vite + React SPA with a typed API client, and the shop UI with safe optimistic updates.
- **15.4 Verification & Shipping:** supertest + Playwright, CI quality gates, a full security pass, and a README a stranger can run.
