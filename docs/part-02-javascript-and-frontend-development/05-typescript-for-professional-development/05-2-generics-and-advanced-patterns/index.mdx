Once your codebase grows beyond a few functions, duplicating wrapper types (`PaginatedUsers`, `PaginatedOrders`, `PaginatedTasks`) creates maintenance drag. **Generics**, **utility types**, and **strict compiler flags** let you write reusable, rock-solid containers and API helpers without sacrificing type precision.

## Lessons in Subchapter 05.2

1. **[05.2.1 Generic Functions and Constraints](/book/part-02-javascript-and-frontend-development/05-typescript-for-professional-development/05-2-generics-and-advanced-patterns/05-2-1-generic-functions-and-constraints):** Type parameters (`<T>`), preserving relationship between inputs and outputs, `extends` constraints, and `keyof`.
2. **[05.2.2 Utility Types and Mapped Types](/book/part-02-javascript-and-frontend-development/05-typescript-for-professional-development/05-2-generics-and-advanced-patterns/05-2-2-utility-types-and-mapped-types):** `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `ReturnType`, and transforming existing models instead of duplicating fields.
3. **[05.2.3 Strict Compiler Configuration](/book/part-02-javascript-and-frontend-development/05-typescript-for-professional-development/05-2-generics-and-advanced-patterns/05-2-3-strict-compiler-configuration):** Essential `tsconfig.json` settings (`strict`, `noUncheckedIndexedAccess`, `noImplicitReturns`) and why enabling strict mode early saves weeks later.
