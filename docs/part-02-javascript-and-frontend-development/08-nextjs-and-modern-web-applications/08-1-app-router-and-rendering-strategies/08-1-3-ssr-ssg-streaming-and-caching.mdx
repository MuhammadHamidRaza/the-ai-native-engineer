Next.js chooses between building HTML **once at build time (`SSG`)** and rendering HTML **per request (`SSR`)**—or streaming slow sections incrementally so the browser paints fast shell UI immediately. Knowing when routes become static vs. dynamic stops stale-data bugs before launch.

## 1. Static Rendering (`SSG`) vs. Dynamic Rendering (`SSR`)

- **Static (`○` in `next build` output):** Generated once at build time (`npm run build`). Ultra-fast CDN delivery; ideal for marketing pages, docs, and blog posts.
- **Dynamic (`ƒ` in `next build` output):** Re-rendered on the server on every request. Triggered automatically when a route reads per-request APIs (`cookies()`, `headers()`, `searchParams`), opts out of caching (`export const dynamic = "force-dynamic"`), or fetches uncached data (`fetch(url, { cache: "no-store" })`).

For known dynamic slugs at build time (like `/blog/[slug]`), export `generateStaticParams()` to pre-build those pages statically.

## 2. Streaming Slow Sections with `<Suspense>`

Without `<Suspense>`, one slow 1,200ms database query holds back the **entire HTML response**. Wrapping slow Server Components in `<Suspense>` streams the navbar and heading immediately while sending the heavy panel as soon as it resolves:

```tsx
import { Suspense } from "react";

async function SlowMetrics() {
  await new Promise((r) => setTimeout(r, 800));
  return <p>Active deployments today: 42</p>;
}

export default function DashboardPage() {
  return (
    <main className="p-6 space-y-4">
      <h1 className="text-2xl font-bold">Overview</h1>
      <Suspense fallback={<p>Loading metrics...</p>}>
        <SlowMetrics />
      </Suspense>
    </main>
  );
}
```

## 3. On-Demand Revalidation (`revalidatePath` / `revalidateTag`)

After mutating data in a Server Action (`08.2.1`), call `revalidatePath("/projects")` so cached route data refreshes immediately instead of showing stale pre-mutation counts.

## 4. Practice Exercises

1. Run `npm run build` in your Next.js starter and inspect the route table symbols (`○` Static vs. `ƒ` Dynamic) printed in your terminal.
2. Add `<Suspense fallback={<p>Loading...</p>}>` around an artificial 1-second `async` Server Component and watch instant shell rendering in the browser Network tab.

## Mastery Checklist

- [ ] Distinguishes build-time Static (`○`) vs. request-time Dynamic (`ƒ`) routes in `next build`.
- [ ] Uses `<Suspense>` so slow data queries do not block fast page shells.
