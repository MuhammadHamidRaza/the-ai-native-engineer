The **DOM (Document Object Model)** is the live tree of JavaScript objects the browser creates after parsing HTML. Subchapter **06.3** connects your JavaScript skills from Chapter 04 straight to the browser: manipulating elements safely without XSS holes, handling user interactions efficiently with event delegation, persisting state with `fetch` and `localStorage`, debugging in DevTools, and assembling a complete responsive interactive page end-to-end.

## Lessons in Subchapter 06.3

1. **[06.3.1 DOM Tree, Events and Delegation](/book/part-02-javascript-and-frontend-development/06-html-css-and-browser-development/06-3-the-browser-dom-and-web-apis/06-3-1-dom-tree-events-and-delegation):** Selecting nodes, `textContent` vs `innerHTML` XSS safety, event bubbling, `event.target.closest()`, and `preventDefault()`.
2. **[06.3.2 Fetch API, Storage and Browser DevTools](/book/part-02-javascript-and-frontend-development/06-html-css-and-browser-development/06-3-the-browser-dom-and-web-apis/06-3-2-fetch-api-storage-and-browser-devtools):** Browser `fetch()` + `localStorage` limits, DevTools Network/Console/Elements debugging, plus a complete interactive Quick Notes Board page project.
3. **[06.3.3 Lab: Calling a Real API — fetch, CORS and DevTools](/book/part-02-javascript-and-frontend-development/06-html-css-and-browser-development/06-3-the-browser-dom-and-web-apis/06-3-3-calling-a-real-api-fetch-cors-and-devtools-lab):** A real browser-to-backend lab — dependency-free Node API, same-origin vs cross-origin, loading/empty/success/error states, and a live CORS failure you then fix honestly (OPTIONS preflight included).
