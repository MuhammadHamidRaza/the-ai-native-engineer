## 1. `localStorage` Rules & Security Limits

`localStorage` stores small key-value **strings** (`~5 MB` max) synchronously on the user's device:
- **Use it for:** UI preferences (dark mode, sidebar collapsed, non-sensitive drafts).
- **Never store:** API secrets, admin passwords, or sensitive PII—any JavaScript on your origin (including third-party scripts or XSS) can read `localStorage`!
- Always wrap `JSON.parse(localStorage.getItem(key))` in `try/catch` in case storage is corrupted or blocked in private browsing.

**`app.js`:**

```javascript
const STORAGE_KEY = "quick-notes-v1";
const THEME_KEY = "quick-notes-theme";

const htmlEl = document.documentElement;
const themeBtn = document.querySelector("#theme-btn");
const form = document.querySelector("#note-form");
const grid = document.querySelector("#notes-grid");
const statusMsg = document.querySelector("#status-msg");

function loadNotes() {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? JSON.parse(raw) : [];
  } catch {
    return [];
  }
}

let notes = loadNotes();

function saveAndRender(announcement = "") {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(notes));
  grid.replaceChildren(
    ...notes.map((n) => {
      const li = document.createElement("li");
      li.className = "note-card";
      const span = document.createElement("span");
      span.textContent = n.text;
      const btn = document.createElement("button");
      btn.type = "button";
      btn.dataset.deleteId = n.id;
      btn.textContent = "Delete";
      li.append(span, btn);
      return li;
    })
  );
  if (announcement) statusMsg.textContent = announcement;
}

const savedTheme = localStorage.getItem(THEME_KEY) ?? "light";
htmlEl.dataset.theme = savedTheme;

themeBtn.addEventListener("click", () => {
  const next = htmlEl.dataset.theme === "dark" ? "light" : "dark";
  htmlEl.dataset.theme = next;
  localStorage.setItem(THEME_KEY, next);
});

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const text = String(new FormData(form).get("note") ?? "").trim();
  if (!text) return;
  notes = [{ id: crypto.randomUUID(), text }, ...notes];
  form.reset();
  saveAndRender("Added new note.");
});

grid.addEventListener("click", (e) => {
  const btn = e.target.closest("button[data-delete-id]");
  if (!btn) return;
  notes = notes.filter((n) => n.id !== btn.dataset.deleteId);
  saveAndRender("Deleted note.");
});

saveAndRender();
```

Run `npx serve .` inside `notes-board/` and open `http://localhost:3000`. Add notes, refresh the page, toggle dark mode, resize down to `375px`, and inspect `localStorage` inside DevTools -> **Application** -> **Local Storage**.

## 3. Debugging Browser Issues in DevTools

- **Network Tab (CORS / 4xx / 5xx):** Red requests show exact status codes and response payloads. A `CORS` error means the *remote server* omitted the `Access-Control-Allow-Origin` header allowing your browser origin (`Part 04` shows how to configure CORS properly on your backend).
- **Elements + Styles:** Toggle CSS checkboxes live to test layout fixes before editing files.
