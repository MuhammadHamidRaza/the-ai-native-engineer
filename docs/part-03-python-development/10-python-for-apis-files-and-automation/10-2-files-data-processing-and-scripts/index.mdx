A huge portion of practical engineering and client automation lives outside HTTP servers: cleaning messy spreadsheets, parsing PDF invoices, running repeatable CLI utilities on a schedule, and surviving flaky networks without corrupting data.

## Lessons in Subchapter 10.2

1. **[10.2.1 Working with JSON, CSV and PDFs](/book/part-03-python-development/10-python-for-apis-files-and-automation/10-2-files-data-processing-and-scripts/10-2-1-working-with-json-csv-and-pdfs):** Cross-platform `pathlib.Path`, safe UTF-8 JSON/CSV pipelines, and extracting text cleanly from PDFs with `pypdf`.
2. **[10.2.2 CLI Tools and Scheduled Automation](/book/part-03-python-development/10-python-for-apis-files-and-automation/10-2-files-data-processing-and-scripts/10-2-2-cli-tools-and-scheduled-automation):** Building a complete runnable `argparse` CLI pipeline, scheduling via `cron` or Windows Task Scheduler, and exit codes.
3. **[10.2.3 Reliable Retry and Error Patterns](/book/part-03-python-development/10-python-for-apis-files-and-automation/10-2-files-data-processing-and-scripts/10-2-3-reliable-retry-and-error-patterns):** Exponential backoff + jitter, retrying only transient errors (`429`/`5xx`, never `400`/`401`), idempotency keys, and structured failure logs.
