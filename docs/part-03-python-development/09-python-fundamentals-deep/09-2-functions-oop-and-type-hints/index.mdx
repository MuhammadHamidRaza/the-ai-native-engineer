Subchapter **09.2** covers how real Python applications organize behavior and data cleanly: reusable functions, decorators, context managers (`with`), **all four pillars of Object-Oriented Programming**, modern `@dataclass` records, and combining **static type annotations** with **Pydantic v2** runtime validation.

## Lessons in Subchapter 09.2

1. **[09.2.1 Functions, Decorators and Context Managers](/book/part-03-python-development/09-python-fundamentals-deep/09-2-functions-oop-and-type-hints/09-2-1-functions-decorators-and-context-managers):** `*args`/`**kwargs`, LEGB scope, closures, `@functools.wraps` decorators, and safe resource cleanup with `with` / `@contextmanager`.
2. **[09.2.2 Classes, Dataclasses and Inheritance](/book/part-03-python-development/09-python-fundamentals-deep/09-2-functions-oop-and-type-hints/09-2-2-classes-dataclasses-and-inheritance):** Explicit breakdown of **Encapsulation, Abstraction, Inheritance, and Polymorphism**, comparison table, composition over inheritance, `@dataclass`, and when to avoid classes.
3. **[09.2.3 Type Annotations and Pydantic Models](/book/part-03-python-development/09-python-fundamentals-deep/09-2-functions-oop-and-type-hints/09-2-3-type-annotations-and-pydantic-models):** Modern type hints (`|`, `TypeVar`, `Protocol`, `TypedDict`), `mypy`/`pyright`, why hints don't validate at runtime, and Pydantic v2 `BaseModel`.
