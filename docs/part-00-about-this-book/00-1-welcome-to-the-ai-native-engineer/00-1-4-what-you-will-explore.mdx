Beyond this introductory **Part 00**, the core curriculum of *The AI-Native Engineer* spans exactly **10 Curriculum Parts, 42 Chapters, and 638 focused learning hours**, followed by **5 Permanent Field Appendices (A–E)**. Every part acts as a load-bearing structural floor: nothing in a later part asks you to accept "magic" because the part directly beneath it already explained how that mechanism works under the hood.

Understanding the full 10-part progression upfront turns a 638-hour commitment from an intimidating blur into ten concrete, sequential engineering milestones.

## 2. Detailed Walkthrough of All 10 Curriculum Parts (638 Hours)

### Stage 1: Computing Foundations & Core Languages (`158 Hours`)

#### Part 01 — Foundations (`Chapters 01–03 · 26 Hours`)
You build unshakeable mental models of hardware, operating systems, processes, memory, DNS, IP routing, and HTTPS (`Ch 01 · 8h`); practice structured analytical decomposition, first-principles reasoning, state tracing, and AI output skepticism (`Ch 02 · 8h`); and master VS Code, command-line workflows, package managers, Git branching/GitHub, systematic debugging, and using AI as a tutor without bypassing mastery (`Ch 03 · 10h`).

#### Part 02 — JavaScript & Frontend Development (`Chapters 04–08 · 92 Hours`)
Rather than skimming surface UI snippets, Part 02 invests **92 hours** across five deep modules: JavaScript execution contexts, closures, prototypes, and async event loop (`Ch 04 · 28h`); strict TypeScript generics, narrowing, and discriminated domain contracts (`Ch 05 · 12h`); semantic HTML, responsive CSS, accessibility, and browser rendering pipelines (`Ch 06 · 16h`); component state, effects, and modern React architecture (`Ch 07 · 22h`); and server/client boundaries in Next.js web applications (`Ch 08 · 14h`).

#### Part 03 — Python Development (`Chapters 09–10 · 40 Hours`)
Python powers modern data processing, backend automation, and the majority of production AI/agent tooling (`Ch 30`). You master deep Python idioms, typing, OOP, virtual environments, and async execution (`Ch 09 · 26h`), followed by FastAPI services, structured file/PDF/CSV processing, HTTP clients, and practical automation pipelines (`Ch 10 · 14h`).

### Stage 2: Persistence, Full-Stack Integration, Cloud & Quality (`236 hours`)

#### Part 04 — Databases, Backend & Full-Stack Development (`Chapters 11–15 · 124 Hours`)
Here separate languages converge into persistent multi-user software: normalized relational database design (`Ch 11 · 8h`); deep SQL querying, transactions, and PostgreSQL alongside MongoDB trade-offs (`Ch 12 · 30h`); backend API architecture, auth, validation, and error handling in Node.js (`Ch 13 · 34h`); professional Git collaboration, automated testing, and pull-request review (`Ch 14 · 14h`); and integrating frontend, API, auth, and PostgreSQL into one **Complete Full-Stack Application** (`Ch 15 · 38h`).

#### Part 05 — Deployment, Cloud & DevOps (`Chapters 16–20 · 62 Hours`)
Software that only runs on `localhost` helps nobody. You learn Linux administration, SSH, systemd, and networking (`Ch 16 · 12h`); domains, DNS records, TLS certificates, reverse proxies, and hosting (`Ch 17 · 12h`); multi-stage Docker images and Docker Compose (`Ch 18 · 12h`); automated CI/CD pipelines and core cloud primitives (`Ch 19 · 14h`); and zero-downtime production deployment, secrets hygiene, and incident monitoring (`Ch 20 · 12h`).

#### Part 06 — System Design & Production Quality (`Chapters 21–24 · 50 hours`)
Production systems must hold up under real scale, mistakes, and adversaries: clean modular architecture and trade-off analysis (`Ch 21 · 18h`); security hardening, testing, observability, and incident response (`Ch 22 · 12h`); performance engineering, latency, and scaling bottlenecks (`Ch 23 · 8h`); and PostgreSQL query plans, indexing strategies, backups, and operational tuning (`Ch 24 · 12h`).

### Stage 3: AI-Native Software, Agents, MCP & Automation (`168 hours`)

#### Part 07 — AI-Native Software Development (`Chapters 25–27 · 40 hours`)
You transition from pure deterministic engineering into AI systems and AI-native developer workflows: how foundation LLMs, tokens, latency, streaming, and model APIs work (`Ch 25 · 16h`); systematic prompt engineering, strict structured outputs, and context management (`Ch 26 · 8h`); and spec-driven AI-assisted development pipelines inside real multi-file repositories (`Ch 27 · 16h`).

#### Part 08 — AI Applications, Agents, MCP & Automation (`Chapters 28–36 · 128 Hours`)
The largest technical block in the entire book (`128 hours` across nine chapters) teaches you to build trustworthy production AI systems:
- **Ch 28 (`16h`):** AI-Powered Applications & RAG (chunking, embeddings, hybrid search, permissions, citations).
- **Ch 29 (`12h`):** Agent Architecture & Agentic AI (when to use pipelines vs. loops, planning, routing, termination).
- **Ch 30 (`18h`):** OpenAI Agents SDK with Python (typed tools, handoffs, tracing, structured agent workflows).
- **Ch 31 (`12h`):** Agent Tools, State, Memory & Guardrails (least privilege, input/output safety gates, persistence).
- **Ch 32 (`12h`):** Model Context Protocol (`MCP` — building interoperable tool/resource/prompt servers cleanly).
- **Ch 33 (`12h`):** n8n Workflow Automation (webhooks, retries, human-in-the-loop approvals, business integrations).
- **Ch 34 (`20h`):** AI Workers (asynchronous background queues, idempotency, rate limits, dead-letter recovery).
- **Ch 35 (`12h`):** Multi-Agent Orchestration (handoffs, specialist isolation, determinism around orchestration).
- **Ch 36 (`14h`):** Production AI Systems (golden evaluation suites, regression gating, FinOps token routing, monitoring).

### Stage 4: Career Execution, Products & Integrated Capstone (`76 Hours`)

#### Part 09 — Career, Client Work, Products & Startups (`Chapters 37–41 · 40 Hours`)
Engineering skill converts into real-world impact through five focused modules: team collaboration and engineering communication (`Ch 37 · 6h`); engineering resumes, portfolio storytelling, and technical interviews (`Ch 38 · 8h`); FDE client discovery, freelancing, scoping, and client acquisition (`Ch 39 · 10h`); product thinking and MVP scoping (`Ch 40 · 8h`); and launching and iterating early-stage software startups (`Ch 41 · 8h`).

#### Part 10 — Integrated Capstone (`Chapter 42 · 36 Hours`)
**Chapter 42 — From Real Problem to Production Product (`36h`)** challenges you to discover or define a genuine real-world problem, architect a full-stack + AI/agentic solution, containerize and deploy it cleanly with automated tests and AI evaluations, and ship full operational handover documentation.

## 3. Permanent Field Appendices (A–E)

Immediately following Part 10 sit five permanent field playbooks designed for ongoing reference after graduation:
- **Appendix A — Complete Client Acquisition Playbook:** Discovery frameworks, value framing, scoping checklists, and structured proposal patterns.
- **Appendix B — Practical Client Outreach Rules & Templates:** Ethical, non-spam outreach structures anchored on specific workflow observations.
- **Appendix C — Client Hunting Practice Workbook:** Guided daily/weekly exercises for practicing problem discovery and audit notes.
- **Appendix D — Job Search & Career Resources:** Portfolio audit sheets, technical interview preparation prompts, and role positioning guides.
- **Appendix E — Developer Reference Materials:** Rapid lookup sheets for Git, CLI, PostgreSQL, HTTP status codes, Docker, and environment debugging.

## 4. Common Misconceptions About the Curriculum Map

1. **"Chapters 37–41 are 'soft non-technical filler'."** False. Scoping vertical slices accurately, running discovery interviews without inventing features, designing viable SaaS unit economics around token costs, and executing clean handovers are core responsibilities of senior, Founding, and Forward Deployed engineers.
2. **"I must wait until Part 09 to build anything useful."** Every stage from Part 02 upward produces working software—from responsive frontends and typed APIs through deployed full-stack apps and automated RAG/MCP services (`00.1.5`).

Open the interactive [All 42 Chapters Index](/chapters) alongside this page and identify:
- **Two chapters in Parts 01–06** covering mechanics you already partially know—but want to verify rigorously from first principles (for example, `Ch 12` SQL transactions or `Ch 18` Docker).
- **Three chapters in Parts 07–10** that excite you most (`Ch 28` RAG, `Ch 32` MCP, `Ch 34` AI Workers, `Ch 39` Client Discovery, etc.), and trace *which earlier chapters* feed directly into them so you appreciate why the sequence holds together.

## 6. Key Takeaways

- **10 Parts, 42 Chapters, 638 Focused Learning Hours + Appendices A–E** form one continuous dependency stack (`158h` Stage 1 → `236h` Stage 2 → `168h` Stage 3 → `76h` Stage 4).
- **Part 00 stays outside the 638-hour count** as orientation and readiness setup.
- **Deterministic craft occupies ~60% of the book** (`394h` across Parts 01–06) because trustworthy AI and FDE delivery sit directly on top of it.
