**27.1 Spec-Driven Workflows** is where this chapter earns its keep. Agents do not fail because they are lazy; they fail because the human never said exactly what "done" means. This section teaches you to write specs an agent cannot misread, split work into agent-sized tasks, and run those tasks through a disciplined loop with gates.

## Topics in 27.1

- **27.1.1 Writing Unambiguous Technical Specs** — why vague requirements produce hallucinated code; the anatomy of a buildable spec (context, problem, goals, non-goals, Given/When/Then acceptance criteria, interfaces, constraints, exit gate, rollback); a complete ShopCore "abandoned cart email" spec; the pre-handoff review ritual; spec linting for ambiguity; how agents earn your trust, and why.
- **27.1.2 Decomposing Tasks for Coding Agents** — vertical vs horizontal slices, the ~30-line-diff-per-PR rule of thumb, task files with explicit context lists, dependency ordering, parallelism with conflict prediction; a worked decomposition of the abandoned-cart spec into 6 sequenced tasks; why "build me a dashboard" fails while six gated tasks succeed.
- **27.1.3 The Agent Phase Kit: Specify, Review, Plan, Verify, Gate** — a case study of one open-source workflow kit (AGENTS.md / PHASES.md / PROGRESS.md / IDEAS.md); fresh-session discipline; compaction and resume; recovery from a dead phase; honest strengths, weaknesses and failure modes; comparison with GitHub Spec Kit, BMAD and OpenSpec; when not to use any of it.

## What You Will Be Able to Do

- Write a spec a coding agent can build from without inventing requirements.
- Reject a spec until its acceptance criteria are objectively checkable.
- Break any feature into small, ordered, independently verifiable tasks.
- Run a multi-session agent project without losing context or discipline.

## How to Work Through 27.1

27.1.1 and 27.1.2 are sequential; 27.1.3 is the capstone. After 27.1.1 you will have drafted (and linted) one real spec. After 27.1.2 you will have decomposed it. 27.1.3 then shows you what it looks like to run those two skills across many sessions on a live feature, and where the loop breaks. Do the exercises with the ShopCore abandoned-cart feature — it is the running example for the whole of 27.1. If you prefer your own codebase, keep it consistent across all three lessons and one artifact will accumulate across the section.

**You will finish this section with:** a linted spec, a six-task decomposition with context lists, gate definitions, and a second-pass critique of the Agent Phase Kit against your own workflow.

**Prerequisites:** Chapters 25-26 (AI tooling foundations) and Git fluency from Part 04. You should be comfortable reading a diff and running a test suite.
