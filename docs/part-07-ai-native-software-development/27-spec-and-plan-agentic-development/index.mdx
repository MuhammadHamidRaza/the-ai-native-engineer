**Chapter 27 (`16 Focused Hours`)** is where Part 07 pays off: supervising AI agents to do real engineering — safely, verifiably, and without losing your own craft.

## Chapter 27 Structure

- **27.1 Spec-Driven Workflows:** Unambiguous specifications; task decomposition sized for agents; the Agent Phase Kit — Specify → Review → Plan → Review → Tasks → Implement → Verify → Gate — as a complete field guide with strengths, limits and failure recovery.
- **27.2 Direct AI Coding Assistants:** Install, configure and supervise Claude Code and OpenAI Codex CLI; evaluate Cursor, OpenCode and Gemini CLI honestly; master slash commands, skills, permissions, sandboxing and harness engineering.
- **27.3 Verification & Ownership:** Audit AI-generated diffs; use tests as guardrails; measure real productivity; own what you ship — responsibility never transfers to the tool.

## What You Will Be Able to Do

- Run a complete project from spec to merged PR with an agentic pipeline — and know exactly which parts the agent wrote, which parts you verified, and which parts stay wrong unless you catch them.
- Open a fresh session, resume a stalled phase, and finish it without losing context.
- Supervise agents responsibly: permissions, sandboxing, secret hygiene, cost control, and honest limits.

Prerequisites: Parts 04–06 (testing, Git) and Chapters 25–26.
