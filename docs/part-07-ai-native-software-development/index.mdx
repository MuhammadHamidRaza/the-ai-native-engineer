Part 07 answers one question honestly: **how do you actually work with AI — every hour of your day, in life, at work, and in code — without outsourcing your judgment or your career?**

Most AI chapters teach either hype ("agents will code for you") or nothing (listicles of tools). This part teaches the two things that compound: **your own engineering fundamentals** (Parts 01–06) and **AI as a disciplined multiplier** — assistants for thinking and writing, coding agents for building, and the verification habits that keep both honest.

## Part 07 Structure

- **Chapter 25 — AI Assistants & Language Models:** How to use ChatGPT, Claude and Gemini for ordinary professional work, and how language models actually work — tokens, context, cost, latency — plus programmatic access with streaming and tools.
- **Chapter 26 — Prompt & Context Engineering:** The craft of instructions: roles, constraints, output contracts, few-shot examples, context budgeting, prompt injection defenses, evaluation and regression checks.
- **Chapter 27 — Direct AI Coding Assistants & Agentic Workflows:** Spec-driven development, the Agent Phase Kit (specify → review → plan → tasks → implement → verify → gate), Claude Code and Codex CLI, Cursor, OpenCode and Gemini CLI, slash commands, skills, permissions, harness engineering, and the discipline of auditing AI-generated code.

## What You Will Be Able to Do After Part 07

- Pick the right assistant for the job — and know when *not* to use one.
- Write prompts that survive contact with real tasks — and test them with evaluation suites that catch regressions.
- Run a complete AI-assisted engineering project from spec to merged PR with verification gates, proof, and human approval where it matters.
- Work inside Claude Code / Codex CLI / Cursor / OpenCode / Gemini CLI with eyes open about permissions, sandboxing, cost, and failure modes.
- Maintain ownership of what you ship: tests as guardrails, diffs audited line by line, secrets never pasted, and an honest record of what you can and cannot verify.

## Prerequisites

Parts 01–06. You need the foundations (syntax, types, HTTP, databases, testing, Git) to supervise — not merely invoke — AI. If you skipped them, pause here and go back; AI accelerates both competence and incompetence.

Part 08 builds the *other* half of the story — systems that use AI — and assumes this chapter's vocabulary.
