Part 07 taught you how to work *with* AI — assistants, spec-driven coding, audited diffs. **Part 08 is the other half: AI *inside* the software you ship.** Here you stop directing a coding assistant and start building products whose own features are powered by models — answered questions, taken actions, automated workflows — for real ShopCore customers.

## The 9-Chapter Journey

Each chapter adds one capability layer to the same running product: **ShopCore HelpBot**, which answers customer questions from ShopCore policy documents (returns, shipping, security, privacy), cites its sources, refuses when it does not know, escalates when it is unsure, and logs everything.

## Who This Is For — and the Honest Prerequisites

This part assumes **Part 04** (JavaScript/Node/Postgres/Express — ShopCore itself), **Part 05** (deployment and operations mental models), **Part 06** (system design, testing, observability), and **Part 07** (LLM vocabulary: tokens, context, structured outputs, prompt injection). Every chapter assumes you can read TypeScript comfortably; Chapter 30 goes deep on Python. If you have not built ShopCore yet, go back — AI features bolt onto a real system, not onto a tutorial snippet.

## What You Will NOT Learn Here

No fine-tuning, no training from scratch, no ML research, no GPU clusters. You will use hosted models and embeddings APIs as building blocks. Model quality is treated as an input to manage, not a dial to invent.

## Verified November 2026

Model names and API shapes in this part were checked against official OpenAI, Cohere, pgvector and BAAI documentation in **November 2026** (e.g. `gpt-6.1-sol` and `gpt-6-astra` via the Responses API, `text-embedding-3-small` at 1536 dimensions). APIs drift — before you ship anything, re-check the linked official docs for the exact model IDs and prices current that month.

## What You Will Be Able to Do After Part 08

- Build a citation-grounded RAG assistant that refuses honestly instead of hallucinating.
- Design agent architectures and explain when a workflow beats an autonomous loop.
- Ship MCP servers that safely expose tools to any compliant AI client.
- Automate business processes with n8n and role-specific AI workers.
- Operate AI systems: evaluations, telemetry, governance and continuous improvement.

Hours honesty: budget **50–70 focused hours** for this part, like every part in this book — less if ShopCore is fresh in your mind, more if agents are new to you. Rushing Chapter 28 to "get to the agents" produces confident garbage later.
