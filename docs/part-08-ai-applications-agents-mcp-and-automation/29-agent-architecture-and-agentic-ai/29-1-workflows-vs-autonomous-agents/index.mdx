**Subchapter 29.1** is the judgment chapter. Before you pick a framework, pick a point on the spectrum: deterministic pipeline, tool-using workflow, or autonomous agent — and understand exactly what each choice costs you in auditability, flexibility, and money.

## Lessons in Subchapter 29.1

1. **[29.1.1 Deterministic Pipelines vs Dynamic Loops](/book/part-08-ai-applications-agents-mcp-and-automation/29-agent-architecture-and-agentic-ai/29-1-workflows-vs-autonomous-agents/29-1-1-deterministic-pipelines-vs-dynamic-loops):** The spectrum, when each end wins (compliance-heavy flows stay deterministic; ambiguous exploration earns an agent), the ShopCore Postmaster specification, and failure modes of both architectures.
2. **[29.1.2 Planning, Reflection and Tool Selection](/book/part-08-ai-applications-agents-mcp-and-automation/29-agent-architecture-and-agentic-ai/29-1-workflows-vs-autonomous-agents/29-1-2-planning-reflection-and-tool-selection):** Plan-and-Execute vs interleaved ReAct, the reflection pattern and when it is noise, and how models select among many tools — with full Postmaster tool signatures.

Work 29.1.1 first. The Postmaster spec you sketch there is the artifact you build in Chapter 30.
