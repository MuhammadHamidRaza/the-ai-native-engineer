1. **[32.1.1 Hosts, Clients, Servers and Transports](/book/part-08-ai-applications-agents-mcp-and-automation/32-model-context-protocol-mcp/32-1-protocol-architecture-and-primitives/32-1-1-hosts-clients-servers-and-transports):** the fragmentation MCP fixes; host vs client vs server; stdio for local and Streamable HTTP for remote (legacy SSE deprecated — retirement path); the full lifecycle of one `tools/call` in an ASCII sequence diagram; current SDKs and their versions; the registry pointer.
