**Subchapter 19.1** teaches the vocabulary every cloud shares — regions, zones, networks, identities, bills — then makes you use it on a real AWS account and shows you the Azure/GCP equivalents of the same twelve services.

## Lessons in Subchapter 19.1

1. **[19.1.1 Cloud Regions, Networking, IAM and Billing Controls](/book/part-05-deployment-cloud-and-devops/19-cloud-engineering-devops-cicd-and-iac/19-1-cloud-fundamentals-and-aws-azure-google-cloud/19-1-1-cloud-regions-networking-iam-and-billing-controls):** Regions vs Availability Zones, VPCs/subnets/public-private IPs, IAM users vs roles vs policies (least privilege) — and the non-negotiable first step: a $5 budget with an email/SNS alert **before** creating any resource.
2. **[19.1.2 AWS Core Infrastructure and Hands-On Workload Lab](/book/part-05-deployment-cloud-and-devops/19-cloud-engineering-devops-cicd-and-iac/19-1-cloud-fundamentals-and-aws-azure-google-cloud/19-1-2-aws-core-infrastructure-and-hands-on-workload-lab):** IAM user with MFA and least-privilege policy → EC2 t3.micro (Amazon Linux 2023) → SSH → nginx → host the ShopCore SPA build → Elastic IP → **mandatory teardown**.
3. **[19.1.3 Azure, Google Cloud and Service Equivalents](/book/part-05-deployment-cloud-and-devops/19-cloud-engineering-devops-cicd-and-iac/19-1-cloud-fundamentals-and-aws-azure-google-cloud/19-1-3-azure-google-cloud-and-service-equivalents):** The twelve-service equivalence table (EC2/VM/Compute Engine, S3/Blob/Cloud Storage, IAM/Entra ID/Cloud IAM…) and exactly where to verify live pricing, free-tier limits and quotas.

**Do not skip 19.1.1.** The labs in 19.1.2, 19.2.2 and 19.3.1 create real, billable resources; your budget alert is the seatbelt.
