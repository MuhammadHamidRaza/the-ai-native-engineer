**Subchapter 16.1** is the theory and judgment half of deployment: what actually changes when code leaves your laptop (builds, ports, env vars, CORS), and how to choose *where* it should run. Get this right and the rest of the chapter is execution; skip it and every deploy becomes superstition.

## Lessons in Subchapter 16.1

1. **[16.1.1 Local to Production: Builds, Ports, Env Vars and CORS](/book/part-05-deployment-cloud-and-devops/16-deployment-foundations-domains-dns-and-hosting/16-1-deployment-fundamentals-and-hosting-models/16-1-1-local-to-production-builds-ports-env-vars-and-cors):** What `npm run build` emits, previewing the artifact locally, dev vs production ports and env vars, `.env` handling that cannot leak, and CORS worked through the exact browser error message.
2. **[16.1.2 Hosting Types and Free vs Paid Limits](/book/part-05-deployment-cloud-and-devops/16-deployment-foundations-domains-dns-and-hosting/16-1-deployment-fundamentals-and-hosting-models/16-1-2-hosting-types-and-free-vs-paid-limits):** A decision matrix across static/CDN, PaaS, containers, VPS, serverless and managed databases — plus an honest free-vs-paid table with approximate limits as of Nov 2026 and links to each provider's own limits page.

Work 16.1.1 before 16.1.2 — the hosting matrix only makes sense once you know which artifacts you are choosing a host *for*.
